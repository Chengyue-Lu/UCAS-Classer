# v1.0.1 -> v1.1.0 进度

更新时间：2026-03-17

## 当前判断

`v1.1.0` 已进入发布基线。  
当前工作重点不再是“为 `1.1.0` 收口”，而是“围绕已发布主线继续做小步稳定性优化和体验精修”。

## 已完成

### 登录与运行时

- SEP 登录保存
- `auth:check` API 化
- 启动自动 `check + full collect`
- 自动 collect 拆成 `summary / full`
- `summary` 发现 diff 后自动挂起下一次 `full`

### 采集与展示

- 课程列表、模块入口、资料、通知、作业主线 request 化
- SQLite 导库稳定
- dashboard 已支持学期分类展示
- 作业详情已支持按需抓取并缓存

### 下载

- 下载目录系统选择器
- 课程分目录
- 课程分目录按学期过滤展示
- 资料批量下载
- 保留资料树文件夹层级
- 下载状态栏

### 桌面壳层

- 托盘常驻
- 单实例
- 自动侧收 MVP
- dock 置顶语义
- 托盘与窗口恢复主线已基本稳定

### 通知能力

- full import 后的新通知 / 新资料 / 新作业系统提醒
- 提醒按课程聚合
- 首次建立基线不提醒历史存量

### 结构整理

- 前端已拆成 `src/app/*.js` 模块
- Rust 壳层已拆出 `desktop_shell.rs`
- TS request 解析域已拆分
- 前端 / Rust / TS 三条线都已有专项审计文档并已归档

## 发布后 Focus

### 体验打磨

- 自动侧收动画与 hover 手感继续精修
- 作业详情内容清洗继续精修
- 图片查看体验后续再单独设计，不沿用已回退的独立窗口尝试

### 发布后验证与跟踪

- 继续观察系统提醒真实行为
- 继续观察 dock / tray / 最小化 / 恢复路径的长期稳定性
- 继续观察作业详情缓存命中与失效逻辑
- 继续验证开发端与打包端在后续迭代中的同步一致性

## 暂不继续扩展

- 作业代提交
- 更重的图片预览窗口能力
- 更多 SEP 扩展能力
- 非必要的纯视觉重做

## 版本判断

`v1.1.0` 现在已经从“目标版本”切换成“当前版本”。  
后续更适合按 `1.1.x` 的维护节奏继续推进，而不是再回到大范围结构改造。
